# Ecommerce Website

An e-commerce website developed using React JS during L&T training.

## Features
- Home page
- Product cards
- Navigation bar
- Login page
- Sign-up page

## Technologies Used
- React JS
- JavaScript
- HTML
- CSS
- Vite

## How to Run

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the application:

   ```bash
   npm run dev
   ```
